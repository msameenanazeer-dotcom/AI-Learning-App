🔎 Breadth First Search

BFS explores nodes level by level.

Example Graph


        A
       / \
      B   C
     / \   \
    D   E   F

BFS Algorithm

  1. Put the starting node into a queue.
  2. Remove the first node from the queue.
  3. Visit the node.
  4. Add its unvisited children to the queue.
  5. Repeat until the goal is found.

🌲 Depth First Search

DFS explores one branch deeply before backtracking.

Example Graph


        A
       / \
      B   C
     / \   \
    D   E   F

DFS Algorithm

  1. Start from the root node.
  2. Visit the node.
  3. Move to an unvisited child.
  4. Continue deeply.
  5. Backtrack when no unvisited child exists.

⭐ A* Search Algorithm

A* combines path cost and heuristic information.

Evaluation Function

f(n) = g(n) + h(n)

g(n) = actual cost from start to node n

h(n) = estimated cost from n to goal

f(n) = total estimated cost
