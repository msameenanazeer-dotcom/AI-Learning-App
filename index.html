🧩 8 Puzzle Problem

Move the tiles and reach the goal state.

What is the 8-Puzzle Problem?

The 8-puzzle is a classic Artificial Intelligence problem consisting of eight numbered tiles and one blank space arranged in a 3 × 3 grid.

The objective is to move the tiles from an initial state to a specified goal state.

Initial State

7    2    4
5    -    6
8    3    1

Goal State

1    2    3
4    5    6
7    8    -

🔎 Breadth First Search

BFS explores nodes level by level.

What is BFS?

Breadth First Search is an uninformed search algorithm.

It explores all nodes at the current depth before moving to the next depth.

BFS uses a Queue.

Example Graph 


        A
       / \
      B   C
     / \   \
    D   E   F
Click "Run BFS" to start.

BFS Steps

  1. Start with the root node.
  2. Put the node into a queue.
  3. Remove the first node.
  4. Visit the node.
  5. Add unvisited neighbouring nodes.
  6. Repeat until the goal is found.

🌲 Depth First Search

DFS explores one branch deeply before backtracking.

What is DFS?

Depth First Search is an uninformed search algorithm.

DFS explores a path as deeply as possible before backtracking.

DFS can be implemented using a Stack or recursion.

Example Graph 


        A
       / \
      B   C
     / \   \
    D   E   F
Click "Run DFS" to start.

DFS Steps

  1. Start from the root.
  2. Visit the current node.
  3. Move to an unvisited child.
  4. Continue deeply.
  5. Backtrack when necessary.

⭐ A* Search Algorithm

A* combines actual path cost and heuristic information.

What is A*?

A* is a heuristic search algorithm commonly used for finding a low-cost path from a start node to a goal node.

A* Evaluation Function

f(n) = g(n) + h(n)

g(n) = Actual cost from the start node to node n.

h(n) = Estimated cost from node n to the goal.

f(n) = Estimated total cost.

A* Search Demonstration

Click "Run A*" to start.

A* Steps

  1. Start from the initial node.
  2. Calculate g(n).
  3. Calculate h(n).
  4. Calculate f(n) = g(n) + h(n).
  5. Select the node with the lowest f(n).
  6. Continue until the goal is reached.
